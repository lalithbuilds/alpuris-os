ALPURIS OS

The world's first open-source operating system for sovereign living agent metropolises. Simulating 100 autonomous AI citizens with PIANO dual-speed cognition, self-organizing across 23 dynamic sectors with a real-time stock market, municipal voting assembly, streaming newsroom, zero-asset procedural Web Audio synthesis, and an interactive 3D WebGL voxel city.

Concurrent System-1 reflexive reflexes (~10Hz) and System-2 deliberative reasoning (~1Hz) driving 100 autonomous agents with memory provenance.

🧊 3D WebGL Voxel Engine (60 FPS)

Three.js procedural city with dynamic monsoon storm lightning, vehicle headlight light cones, ground halos, and rotating holographic beacons.

🎵 Zero-Asset Procedural Web Audio

Direct browser AudioContext synthesis generating pink noise monsoon rain, resonant thunderclaps, and electric metro kinetic hum.

👤 Citizen Dossier Cockpit

Frosted-glass slide-out telemetry panel streaming live citizen thoughts, wallet balances, stamina, and Citizen Voice Radio.
