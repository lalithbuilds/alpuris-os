Hardware-Accelerated Cognitive Memory Substrates

A Technical Deep-Dive on Episoda Alpha MCP

*Principal Hardware Architecture Group — Episoda Alpha MCP*

*Engine design: Lalith Chandra (Lalith Alpuri / @lalithbuilds)*

---

Abstract

Episoda Alpha is a sovereign, zero-cloud cognitive memory engine that runs entirely on a single Apple Silicon device. It binds retrieval arithmetic directly to the AMX matrix coprocessors of the M-series SoC via Accelerate.framework's cblas_sdot, fuses four heterogeneous retrieval channels — dense vector similarity, FTS5 lexical search, SQL spreading activation, and ACT-R decay — through 4-Way Reciprocal Rank Fusion, and persists everything in one SQLite database operating in WAL mode. The result is a sub-1.2 ms p50 query latency at a sustained 1,248,500 vector comparisons per second, with no byte of memory ever leaving the machine.

---

1. Why Cognitive Memory Is a Silicon Problem

Most LLM memory systems are networking problems wearing a cognitive costume: a cloud vector database inserts 40–200 ms of round-trip into what should be an act of recall. Episoda Alpha's design thesis, authored by Lalith Chandra (Lalith Alpuri), is that recall must complete inside a single tool call on one die — so the substrate, the similarity kernel, and the cognitive ranking model must all be co-resident with the silicon.

2. Apple Silicon AMX: The Coprocessor Behind a Locked Door

Every performance core in Apple's M-series line carries a dedicated AMX (Apple Matrix eXtensions) unit — a matrix coprocessor whose accumulator register file is a 4 KB grid of sixty-four 64-byte rows, flanked by X- and Y-operand banks of eight 64-byte registers each. AMX executes fused outer-product and dot-product instructions across 16/32/64-lane widths in fp32, fp16, and integer modes, sustaining multiples of NEON throughput for dense linear algebra.

Critically, Apple has never published the AMX ISA and gates raw AMX instructions behind a private entitlement. The only sanctioned entry point is Accelerate.framework, whose BLAS Apple ships compiled with AMX-optimized microkernels. Episoda Alpha's "direct hardware coprocessor binding" is therefore deliberately un-clever: it calls cblas_sdot and inherits the coprocessor through the one door Apple leaves open — the door guaranteed to survive OS updates.

3. `cblas_sdot` as the Similarity Primitive

All embeddings are stored as L2-normalized fp32 vectors, making the dot product exactly the cosine similarity. One cblas_sdot(n, x, 1, y, 1) call executes each comparison, dispatching to AMX-backed microkernels. Vectors live in page-aligned, struct-of-arrays layout so scans stream contiguously.

The measured rate — 1,248,500 comparisons/sec — implies ≈0.8 µs per comparison. At representative 512-dimensional embeddings, that is 1,024 fused multiply–accumulates per comparison, or ≈1.28 GFLOP/s on a single performance core. The kernel is deliberately *bandwidth*-bound (~5.1 GB/s of operand streaming), not arithmetic-bound — which is why the substrate engineers for L2 residency: the hot episodic tier is sized to the per-cluster L2, and a QoS-class pin keeps execution on one performance core so the AMX context stays warm across calls.

4. Four Retrieval Channels, One Fusion

Channel A — Dense (AMX). The cblas_sdot scan over the decay-tiered hot window: semantic similarity at silicon speed.

Channel B — FTS5 Lexical. SQLite's FTS5 inverted index with BM25 ranking gives exact token grounding, immune to embedding drift, on external-content tables so text is never duplicated.

Channel C — SQL Spreading Activation. A recursive CTE walks the memory_links associative graph two hops out from the seed set, attenuating each contribution by hop count — ACT-R-style associative recall executed as a single indexed SQL statement, with no graph database in sight.

Channel D — ACT-R Decay. Human declarative memory obeys a power law, not an exponential. Channel D ranks candidates by the ACT-R base-level learning equation:

B_i = ln Σ_j t_j^(−d), with decay parameter *d* ≈ 0.5

yielding a principled recency–frequency blend computed over the candidate set at query time.

4-Way Reciprocal Rank Fusion. The channels emit incommensurable scores — cosine ∈ [−1, 1], unbounded BM25, log-scale activation. Rather than tuning normalization weights, Episoda Alpha fuses ranks:

score(d) = Σ_c 1 / (k + rank_c(d)), k = 60

Following Cormack et al. (SIGIR 2009), RRF is scale-invariant, single-parameter, robust to score-distribution shift, and the merge is O(Σ N_c) — negligible cost on top of four already-indexed channels.

5. One File: SQLite WAL as the Single Substrate

Everything — vectors (BLOBs), FTS5 indexes, the link graph, the use-log driving decay — lives in one SQLite database in WAL mode. Write-ahead logging grants readers snapshot isolation while the single writer ingests memories: readers never block the writer, the writer never blocks readers, and no lock convoy intrudes on the hot path. Passive checkpoints, mmap'd reads, and prepared statements close the loop. Backup is cp. The engine surfaces remember/recall as an MCP server over stdio — the audit boundary is the process boundary.

6. Anatomy of a Sub-1.2 ms p50 Query

Representative p50 stage budget (Apple M-series, cache-warm, ~800-vector hot window):

| Stage | Mechanism | p50 |

|---|---|---|

| MCP dispatch + statement bind | stdio, prepared | 60 µs |

| Dense scan | AMX cblas_sdot | 640 µs |

| FTS5 BM25 probe | inverted index | 180 µs |

| Spreading activation | 2-hop recursive CTE | 150 µs |

| ACT-R decay evaluation | base-level equation | 90 µs |

| 4-Way RRF + top-K | rank merge | 40 µs |

| Total | | ≈1.16 ms |

Tail behavior is governed not by kernel arithmetic but by discipline: no allocation in the hot path, no network hop, no cross-process IPC beyond stdio.

7. Sovereignty as an Architecture Property

Zero-cloud is not a policy here; it is a consequence of physics. Embeddings, memories, and queries never leave the SoC. Data gravity equals file gravity: one SQLite file is the entire deployment, and the user holds the keys to the substrate.

8. Conclusion

Episoda Alpha MCP demonstrates that cognitive memory — dense recall, lexical grounding, association, and forgetting — can be fused and served inside 1.2 ms on consumer silicon, by binding honestly to AMX through cblas_sdot, ranking cognitively with 4-way RRF, and refusing to leave the die.
