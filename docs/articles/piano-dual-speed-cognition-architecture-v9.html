Abstract

PIANO (Parallel Intuitive–Analytical Neural Orchestration) is the cognition substrate of ALPURIS OS, an open-source living agent metropolis simulating 100 autonomous AI citizens across 23 dynamic sectors, with real-time stock markets and zero-asset Web Audio procedural synthesis. PIANO bifurcates cognition after the dual-process model: a fixed-rate System-1 reactive tick loop performs perception, drive integration, and action selection every 100 ms with no deliberative cost, while an event-triggered System-2 reflection path performs sparse, expensive goal and identity revision. The two speeds are coupled through a tiered memory plane kept permanently bounded by salience-weighted compaction, and executed over an ECS substrate with spatial neighborhood hashing that renders perception queries O(1) amortized. The result is emergent, city-scale behavior at interactive frame rates on commodity, browser-class hardware.

1. Introduction

The central failure mode of autonomous agent societies is economic: a naive architecture that invokes a deliberative model per agent per tick requires 100 citizens × 10 ticks/s = 1,000 inferences per second — infeasible in cost and latency. The opposite failure is behavioral: pure-heuristic agents degrade into shallow automata with no interiority, no narrative continuity, and no capacity for goal revision.

PIANO resolves the dilemma by taking Kahneman's dual-process theory [2] as an engineering specification rather than a metaphor. System-1 is fast, cheap, and always on; System-2 is slow, expensive, and rare. Everything in ALPURIS OS — the 23 sector economies, the order-book stock market, the procedural ambience — runs off the same deterministic simulation clock that PIANO governs.

2. Architectural Overview

Three planes over a data-oriented ECS core:

1. Simulation plane — fixed-timestep accumulator loop at 10 Hz (dt = 100 ms), deterministic given a seed.

2. Cognition plane — the System-1 loop plus a reflection scheduler that admits System-2 passes under a global budget.

3. Memory plane — a three-tier store whose size is invariant to simulation age, guaranteeing that System-2 prompts never grow unboundedly.

3. System-1: The Reactive Tick Loop

Each tick executes five phases per citizen: spatial hash sync, perception, drive integration, action selection, and event emission. Drives (hunger, energy, wealth-anxiety, social appetite, mood vector) are leaky first-order integrators:

> drive[i] ← clamp(drive[i] + (demand[i] − satiation(action, i)) · dt)

Action selection is an argmax over a compiled utility table (U(a) = Σ w_i(a)·drive_i + w_prox·socialProximity), roughly 40 verbs per sector archetype — no network calls touch the hot path. Reactive dialogue draws from cached per-sector template banks; market actions post limit orders into sector order books; ambience actions emit Web Audio synth triggers keyed by sector. Per-agent budget is sub-100 µs, keeping the full metropolis tick in the sub-millisecond regime.

tick(dt = 100 ms):
  spatialHash.rebuildDirty()                        // ECS Transform mutations only
  for agent in citizens:
    P   = spatialHash.query(agent.pos, R_p)        // 3×3 cell sweep
    D   = drives.integrate(agent, P, dt)
    act = policy.select(agent, D, P)                // argmax, O(1) table lookup
    act.execute(agent, dt)                          // steering, orders, utterances
    T0.push(agent, act.event)                       // raw episodic ring buffer
  market.tickAllSectors()                           // 23 order books matched
  reflectionScheduler.drain(budget)                  // due System-2 passes, if any

4. System-2: Reflection Triggers

A reflection is a deliberate pass in which a citizen inspects its compacted history and revises goals and identity. Reflections are never scheduled unconditionally; they fire on triggers:

  • **Salience accumulation:** cumulative salience ΣS ≥ θ_s over the rolling window.
  • **Goal frustration:** a directive unmet for > N ticks (N = 600 ≈ one simulated hour).
  • **Anomaly:** percept surprise ≥ 3σ from the sector's rolling baseline (crashes, fires, windfalls).
  • **Social threshold:** a relationship weight crossing a tier boundary (acquaintance → friend).
  • **Circadian:** one guaranteed end-of-day review per citizen.

    • Each citizen holds a token bucket (capacity 3, refill 1/simulated day); a global scheduler caps concurrent reflections and spreads them across idle ticks, eliminating thundering-herd cost spikes. The pass itself is a four-stage pipeline: (1) assemble bounded context (identity digest + semantic store + top-k salient episodes by retained salience); (2) deliberate; (3) compile the revised plan into a directive tree that System-1 consumes as utility-override weights; (4) patch the identity digest differentially. This is the loop closure that makes dual-speed cognition coherent: System-2 writes; System-1 executes for the next several thousand ticks.

    5. Memory Compaction

    The memory plane guarantees bounded context — the property that keeps System-2 economically viable at any city age.

    | Tier | Store | Retention | Writer | Reader |

    |---|---|---|---|---|

    | T0 | Raw event ring buffer (512 events/agent) | ~1 simulated day | System-1 | Compactor |

    | T1 | Salient episodic index | decay-gated | Compactor | System-2 |

    | T2 | Semantic fact store + identity digest | permanent, patched | Compactor | System-2 |

    When T0 saturates, the compactor drains it: (1) near-duplicate events are merged via locality-sensitive hashing on embeddings (cosine ≥ 0.92 keeps the max-salience copy); (2) each survivor is scored S = α·novelty + β·|valence| + γ·goalRelevance; (3) events with S ≥ θ_mem promote to T1; (4) entity–relation–object triples are upserted into T2 and the narrative digest is regenerated. A nightly decay sweep applies R(t) = S·e^(−λΔt), demoting episodes below a forgetting floor. Consequently every System-2 prompt is O(|T2| + k) tokens — independent of how long the metropolis has lived.

    6. ECS Spatial Neighborhood Hashing

    All runtime state lives in archetype-chunked, structure-of-arrays ECS storage (Transform, Drives, Wallet, OrderBookRef, MemoryRef, AmbienceSource, SectorTag), giving cache-coherent iteration. Neighborhood perception uses a uniform-grid spatial hash:

  • **Cell size:** c = ⌈1.5 · R_p⌉, so any radius-R_p query resolves within a 3×3 cell sweep.
  • **Key:** quantized coordinates packed as `(ix << 16) | (iy & 0xFFFF)`, hashed FNV-1a into a 2¹³-bucket table.
  • **Update:** dirty-set rebuild — only entities whose Transform mutated reinsert; full rebuild remains viable at this population.
  • **Query:** with mean occupancy k̄ ≈ 8, a perception pass touches ~72 candidates, pruned by squared distance before social and market interaction logic.

    • A second, macro layer partitions the map into the 23 sectors as coarse occupancy lists, giving O(1) sector resolution, order-book fan-in for the market tick, and dispatch onto the ambience bus that drives the zero-asset Web Audio synthesis. Build is O(n), query is O(k̄), memory is O(n + grid).

    7. Emergence and Amortization

    Against the naive per-tick baseline of 1,000 deliberation calls/second, PIANO's token-bucketed reflection regime reduces expensive inference by roughly three orders of magnitude while preserving depth. The observable consequences are structural: commuting waves at sector shift boundaries, genuine price discovery in the sector order books, friendship graphs correlated with spatial co-occurrence, and diurnal mood cycles audible in the procedural ambience. Critically, reflection logs double as first-class observability artifacts — citizen diaries that make the society debuggable.

    8. Conclusion

    PIANO demonstrates that the dual-process model is not merely descriptive but prescriptively buildable. Three invariants carry the system: expensive deliberation amortized across thousands of cheap reactive ticks; memory compaction keeping the slow path's context invariant to age; and spatial hashing keeping the fast path sublinear. Future work includes adaptive per-agent decay rates (λ), cross-metropolis federation via Episoda Alpha MCP, and GPU-resident hash grids.
