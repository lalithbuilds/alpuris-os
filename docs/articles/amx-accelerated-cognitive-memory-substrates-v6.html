AMX Hardware Acceleration in Local Cognitive Memory Substrates

Hardware-Accelerated Cognitive Memory Substrates

1. Design Thesis: Sovereignty Begins at the Silicon

Cloud-hosted memory tiers impose two taxes on cognitive systems: a latency tax (network round-trips, TLS handshakes, queueing) and a sovereignty tax (episodic data crossing the device boundary). Episoda Alpha MCP rejects both by construction. The engine treats Apple Silicon's AMX matrix coprocessor as its primary compute organ, a single SQLite database in WAL mode as its sole persistence organ, and Accelerate.framework's cblas_sdot as the ABI between them. There is no server tier, no external vector database, no embedding round-trip. Retrieval latency becomes a property of local physics — cache lines, datapaths, page faults — rather than of infrastructure.

2. AMX: Apple's Deliberately Undocumented Coprocessor

Apple Matrix eXtensions (AMX) debuted in the A13 Bionic and ship in every M-series SoC, instantiated alongside the performance-core clusters. Each AMX unit owns a 512-byte register file organized as tile registers — 16×16 tiles of 32-bit floats, or 16×32/32×32 at fp16/int16 — and retires full-tile fused multiply-accumulate (FMA) in a single opcode. This is not SIMD. NEON's 128-bit lanes process a handful of fp32 MACs per instruction; AMX executes an entire outer-product tile per operation, a throughput-class advantage on dense linear algebra that no amount of NEON unrolling recovers.

Critically, Apple does not publicly document the AMX instruction set, and hand-written AMX is neither sanctioned nor stable across silicon generations. The supported contract is Accelerate.framework: Apple's hand-tuned BLAS, vDSP, and BNNS kernels that dispatch eligible dense workloads onto the AMX datapaths. Episoda Alpha binds to this contract — and only this contract — which is precisely why one binary runs unmodified from M1 through M4 while the underlying hardware path improves beneath it.

3. `cblas_sdot` as the Retrieval Primitive

cblas_sdot(N, x, 1, y, 1) computes Σxᵢyᵢ — the level-1 BLAS dot product — and Episoda Alpha's dense channel reduces to this single call. Every episode vector is L2-normalized at write time, so a dot product *is* cosine similarity, and the full retrieval scan is a unit-stride sweep of contiguous memory. Three properties make this the ideal substrate binding:

1. Tuned dispatch. vecLib's sdot kernels are per-SoC optimized and route across the widest available datapath, including AMX, without any configuration or hint flags.

2. Substrate locality. Vectors live as BLOBs inside the same mmap'd SQLite pages the other retrieval channels read, so the dense scan is effectively a linear walk of hot cache lines — the comparison loop and the storage engine are one memory hierarchy.

3. Zero dependency. Accelerate ships with the OS. Nothing to install, nothing to link, nothing to breach the sandbox — a decisive property for a sovereign engine.

4. One File, One Substrate: SQLite WAL

All cognitive state — episode payloads, d-dimensional float32 vectors, FTS5 full-text indexes, and weighted association edges — is co-located in one database file in write-ahead logging mode. WAL grants snapshot isolation: a reader acquires a consistent database view in O(page), never blocks the writer, and is never blocked by it. During agent ingestion at full write pressure, query p50 is unperturbed — readers see the last committed snapshot while the writer appends frames.

The consequence for fusion is architectural: all four retrieval channels execute against one address space, joinable by primary key, with no IPC, no serialization, and no network in the critical path. Prepared statements are compiled once and reused; the page cache does the rest.

5. Four Channels, One Ruler: 4-Way Reciprocal Rank Fusion

Episoda Alpha fuses four rankers, each modeling a distinct facet of human memory:

1. Dense semantic recall — the cblas_sdot cosine sweep, top-k.

2. Lexical recall (FTS5) — BM25 over the episode corpus for surface-form precision.

3. SQL spreading activation — a depth-bounded recursive CTE over the weighted association graph; activation diffuses outward from seed episodes surfaced by channels 1–2, recalling associates that share neither tokens nor an embedding neighborhood.

4. ACT-R decay — base-level activation Bᵢ = ln(Σₖ tₖ⁻ᵈ), the power-law forgetting curve from Anderson's ACT-R declarative memory, where tₖ are elapsed times since prior rehearsals and d ≈ 0.5. Recency and rehearsal frequency become first-class physics rather than timestamps bolted on afterward.

These channels emit incomparable score scales — BM25 is unbounded, cosine is [−1,1], activation is log-scaled — so Episoda Alpha fuses ranks, not scores:

> RRF(d) = Σ꜀₌₁⁴ 1 / (k + rank_c(d)), k = 60

following Cormack, Clarke & Buettcher (SIGIR 2009). Rank fusion eliminates score normalization entirely, is robust to any single channel returning empty or degraded results, and is fully deterministic: the same episode corpus always fuses to the same ordering.

6. Anatomy of a Sub-1.2 ms p50

Measured end-to-end MCP tool-call latency decomposes approximately as: dispatch and argument parse ~80 µs; dense cblas_sdot scan ~600 µs; FTS5 BM25 ~150 µs; spreading-activation CTE ~120 µs; ACT-R activation evaluation plus 4-way RRF ~90 µs — roughly 1.04 ms of compute, closing at a ~1.18 ms p50 once page-fault and scheduler jitter are absorbed. Because the AMX path is branch-light and dispatch-stable, p99 tracks p50 closely rather than exhibiting the heavy tail typical of indexed ANN systems.

The headline throughput — 1,248,500 vector comparisons per second — is exactly what it sounds like: 1,248.5 comparisons per millisecond, sustained. At that rate, a p50 query performs an exhaustive, exact — no ANN approximation — scan of approximately 1,499 episode vectors and still finishes inside budget. This is why Episoda Alpha ships no HNSW or IVF index: below roughly 10⁴–10⁵ vectors, a linear AMX sweep is faster than graph traversal, pays no build-time amortization, adds no neighbor-list memory overhead, and — most importantly — is correct by construction, because recall is 100% when nothing was approximated away. The latency headroom is spent on cognitive fidelity instead.

7. Why the GPU Loses at This Scale

Apple's GPU shares unified memory, but a GPU query still pays kernel submission, command-buffer fences, and tile-resident scheduling for small N — overheads irrelevant at microsecond scale. The AMX path is single-shot and microsecond-quantized: dispatch cost is stable, so p50 and p99 stay tight. Determinism, not raw FLOPS, is the scarce resource in interactive memory.

8. Sovereignty as a Protocol Property

Episoda Alpha speaks MCP (Model Context Protocol) over stdio: agents and IDEs receive remember / recall / associate tools, and every embedding, episode, and association remains inside the process boundary. ACT-R decay yields *principled* forgetting — memories fade as a cognitive model predicts, not as a TTL dictates — and 4-way RRF guarantees that degradation of any one channel never degrades the whole.

9. Conclusion

Episoda Alpha MCP demonstrates that cognitive memory for local agents is a solved systems problem when the substrate is chosen correctly: AMX for linear algebra, cblas_sdot as the ABI, SQLite WAL as the single source of truth, and reciprocal rank fusion as the scale-free arbiter of heterogeneous memory signals. Sub-1.2 ms p50 at 1,248,500 comparisons/sec, on-device, zero-cloud. Sovereignty is not a feature — it is a consequence of the architecture.
