Abstract

PIANO is the cognition kernel of ALPURIS OS, the open-source living agent metropolis simulating 100 autonomous AI citizens across 23 dynamic sectors with real-time stock markets and zero-asset Web Audio procedural synthesis. PIANO separates cognition into a fast, deterministic System-1 tick loop (10 Hz utility-driven reactivity) and a slow, deliberative System-2 reflection layer (0.1–1 Hz), coordinated under hard frame budgets. This paper specifies the reactive tick loop and level-of-detail tick stratification, the trigger taxonomy and backpressure policy governing reflection, the salience-decay memory compaction pipeline with template-based gisting, and the ECS spatial hash that unifies perception, locomotion, market clearing, and audio culling in O(1) amortized neighborhood queries. The kernel sustains 60 fps with p99 System-1 cost of 1.8 ms per tick.

1. Introduction

A simulated metropolis fails in one of two ways. Purely reactive agents are alive but amnesiac — they never form intentions, reputations, or narratives. Purely deliberative agents are thoughtful but catatonic — every action waits on a planner. PIANO encodes Kahneman's dual-process model [1] as schedulable engineering: Perceive — Introspect — Act — Note — Organize. The first, third, and fifth verbs run fast; the second and fourth run slow. The name is also a tempo marking: System-1 plays allegro, System-2 adagio — fitting for a metropolis whose entire soundscape is performed by synthesis, never sampled.

2. Architectural Overview

ALPURIS OS is a pure entity-component-system (ECS) simulation: entities — citizens, buildings, market orders, synthesis voices — are sparse-set handles; data lives in struct-of-arrays (SoA) typed arrays; behavior lives in systems run by a deterministic scheduler. PIANO's dual-speed contract is budget-first:

| Lane | Cadence | Budget | Preemption |

|---|---|---|---|

| System-1 tick | 10 Hz (100 ms) | 3 ms/frame | never deferred |

| System-2 reflection | 0.1–1 Hz, event-driven | 2 ms/frame | deferrable, preemptible |

| Memory compaction | amortized | 0.5 ms/frame | deferrable |

| Render + Web Audio | 60 fps | remainder | — |

System-1 must complete within its tick. System-2 work is queued and sliced so no reflection can ever stall the metropolis.

3. System-1: The Reactive Tick Loop

System-1 is a fixed-timestep loop at 10 Hz. Each tick executes, in order: Metabolism → Perception → Decision → Locomotion → Action → Market-Micro.

Tick stratification (LOD). Citizens are assigned tiers: Tier A (near focus) ticks every cycle; Tier B every fifth cycle (2 Hz); Tier C (off-focus, asleep) every twentieth cycle (0.5 Hz), with needs integrating at reduced rates to preserve plausibility. Work per tick stays bounded regardless of population growth.

Metabolism. Each citizen carries a need vector N ∈ [0,1]^k (hunger, energy, social, capital-integrity, rest), integrated explicitly: N ← saturate(N + (α − β·activity)·Δt).

Perception. A 3×3 spatial-hash ring query (§6) around the citizen's cell, filtered by perception radius R = 32 units, yields a salience-ranked observation set of ≤ 24 entries.

Decision. Action selection is utility argmax over sector affordances:

U_i = w_i · saturate(d_i / θ_i) + ε, ε ~ U(0, 0.05)

where w are role weights (rewritten only by System-2). The ε term, drawn from a per-citizen splitmix64 PRNG, provides *reproducible* noise: identical seeds replay bit-identical trajectories, verified via periodic state-hash checkpoints.

Locomotion. Velocity is capped at 5 u/s and steered along the sector landmark graph; local avoidance is a hash-derived repulsion term. No global pathfinding on the hot path — that is System-2's jurisdiction.

Market-Micro. Market orders execute against sector order books in-tick; limit-order clearing is deliberately a *slow* institutional loop (§4).

4. System-2: Reflection Triggers

System-2 runs only when triggered — never on a blind timer — and always deferred: triggers enqueue reflections; the scheduler drains the queue in ≤ 2 ms slices.

Trigger taxonomy (evaluated on the tick's tail, at negligible cost):

  • **Anomaly:** |Δwealth| > 3σ of a 600-tick trailing window; any need ≥ 0.85 sustained for 30 consecutive ticks.
  • **Saturation:** working-memory occupancy ≥ 52 of 64 slots (80%).
  • **Social:** trust or reputation delta > 0.2 in a single interaction; failed transaction.
  • **Planning:** goal deadline missed, or goal achieved.
  • **Periodic floor:** at most one self-reflection per 600 ticks per citizen, so even quiet agents introspect roughly once per simulated minute.

    • Backpressure. The queue is salience-priority ordered; triggers coalesce (five same-kind anomalies within 50 ticks merge into one reflection with combined evidence); the queue caps at 256 pending items, dropping lowest salience. Reflection is lossy-but-bounded, never blocking.

    The reflection pass performs four operations: (1) emits an episode E = (t, actors, act, outcome, valence v ∈ [−1,1], salience σ) into the episodic store — the very store Episoda Alpha MCP exposes to external model-context clients; (2) re-ranks the goal stack; (3) updates trust residually, T[a][b] ← T[a][b] + η·(r − T[a][b]); (4) may rewrite role weights. Slow institutions ride the same lane: every 5 seconds, all 23 sector order books clear limits and mark prices — the market itself deliberates at System-2 tempo.

    5. Memory Compaction

    Each citizen has three tiers: working memory (64-slot ring), episodic memory (cap 512 episodes), and semantic memory (durable gists and milestones). Uncompacted, 100 citizens × 512 episodes is a 51,200-record leak; PIANO holds steady state near 12% of that.

    Salience decay. Each episode carries the score

    S = σ · e^(−Δt/τ) · (1 + |v|), τ = 900 s

    Episodes falling below θ_c = 0.15 enter the candidate set.

    Merge-and-gist. Candidates merge pairwise when Jaccard(actor ∪ action tags) > 0.6; merged clusters reduce to ≤ 3-sentence gists via a deterministic template extractor (subject — action — outcome — aggregate). Because ALPURIS OS is zero-asset and offline-safe, gisting is extractive: no external model calls on the hot path.

    Milestones. Episodes with σ ≥ 0.9 (first trade, sector catastrophe, fortune threshold) bypass decay and pin to semantic memory, forming the life-summary System-2 consults.

    Amortization. Compaction processes 16 entries per frame (≤ 0.5 ms); full passes run only on Tier-C citizens. Result: ~180 KB per-citizen steady state, and reflection latency independent of history length.

    6. ECS Spatial Hashing

    "Organize" is the spatial hash — the substrate every subsystem queries.

    Grid. Cell edge = 64 units = 2R; since a cell is at least twice the perception radius, a 3×3 ring provably covers any R-neighborhood. Because 64 = 2⁶, cell keys are bit shifts: cx = x >> 6, cz = z >> 6.

    Hash. bucket = (cx · 0x9E3779B1 ⊕ cz · 0x85EBCA77) & (M − 1), M = 4096 — a power-of-two table with Fibonacci-mix constants in the Teschner tradition [2]. Buckets are intrusive linked lists of next-indices into entity arrays: zero allocations, cache-friendly.

    Maintenance. Entities reinsert only on cell crossing (~5% of movements per tick); intra-cell motion is free. The 23 sector AABBs are grid-aligned so sector-scoped queries clip *buckets*, not entities; cross-sector perception resolves through the sector adjacency graph, never wider rings.

    Consumers. One hash serves all: System-1 perception rings; locomotion repulsion; proximity-gated market interactions; and Web Audio culling — every synthesis voice (oscillators, noise buffers, envelopes — no samples) is spatialized at its entity position, and only sources hashing near the listener are granted audio-graph nodes. Zero-asset audio is, quite literally, a spatial-hash query. The design targets 10k+ entities, where neighborhood queries remain O(k) in cell occupants rather than O(n) in the world.

    7. Performance

    On mid-range hardware: System-1 p99 = 1.8 ms/tick; hash maintenance < 0.2 ms/frame; reflection queue latency p95 < 1.2 s; steady-state retained episodes ≈ 6,100; frame headroom at 60 fps ≥ 8 ms; replay hash equality verified over 10⁶ ticks.

    8. Conclusion

    PIANO's thesis is that a living metropolis needs two tempos, not one fast one: reactivity buys presence, reflection buys identity, and compaction is what lets a citizen be both old and quick. Spatial hashing is the shared stage on which perception, economy, and sound perform. Future work: hierarchical hash grids toward 1,000 citizens, and a reflection lane shared with external MCP clients via Episoda Alpha.
