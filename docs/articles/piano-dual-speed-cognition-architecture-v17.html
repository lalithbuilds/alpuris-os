Abstract

ALPURIS OS runs a persistent metropolis of 100 autonomous AI citizens inside a browser-only, zero-asset runtime: no servers, no streaming assets, no external inference dependencies. Its cognition kernel, PIANO, resolves the central tension of such a system — believable, reflective behavior versus hard per-tick latency budgets — by partitioning cognition into two tempi on one instrument. This paper specifies the System-1 reactive tick loop (deterministic, 10 Hz, ≤8 ms for all citizens), System-2 reflection triggers (salience- and contradiction-driven, atomically committed), a four-tier memory hierarchy with salience-weighted compaction (≈40:1 compression), and the ECS spatial neighborhood hash that bounds perception cost to O(1) amortized per agent.

---

1. Introduction

Prior generative-agent architectures (Park et al., 2023) demonstrated emergent social behavior but coupled every cognitive step to LLM latency, making them unusable as always-on local simulations. PIANO adopts Kahneman's dual-process framing (2011) as an engineering contract rather than a metaphor: fast thinking must be cheap, deterministic, and interrupt-free; slow thinking must be asynchronous, budgeted, and never able to stall the world. The name encodes the pipeline — Perception, Introspection, Action, Narrative, Orientation — played as two hands on one keyboard: the fast hand (P→A) at allegro, the slow hand (I→N→O) at adagio.

2. The Two Hands

| Stage | Tempo | Cadence | Owner |

|---|---|---|---|

| P — Perception | Allegro | 10 Hz tick | System-1 |

| A — Action | Allegro | 10 Hz tick | System-1 |

| I — Introspection | Adagio | Event-driven | System-2 |

| N — Narrative consolidation | Adagio | Event-driven | System-2 |

| O — Orientation (goal/identity) | Adagio | Event-driven | System-2 |

The invariant that makes dual-speed safe: System-1 reads only a committed snapshot; System-2 writes only to a shadow buffer, swapped atomically at tick boundaries. Reflection can therefore never tear the reactive layer mid-tick.

3. System-1: The Reactive Tick Loop

System-1 executes a fixed-timestep loop at 10 Hz (100 ms budget) for all 100 citizens, staged as:

1. Signal ingest. Market tick deltas (23-sector exchange feeds), sector events, and inbound social pings land in per-citizen mailboxes.

2. Perception. Feature extraction restricted to the citizen's spatial neighborhood (§6) — never global state.

3. Utility scoring. Each candidate action *a* is scored as u(a) = w·f(a), a linear utility model over cached features (energy, holdings, proximity, relationship warmth, sector sentiment). The weight vector *w* is System-1's *actuator*, but System-2 is its *only writer* — reflection adjusts what the fast hand reaches for.

4. Selection & actuation. Top-k softmax with ε-greedy (ε = 0.05) preserves agency; actuation integrates kinematics, enqueues trade orders and speech, and emits events to the zero-asset Web Audio synth bus.

5. Housekeeping. Energy accounting and salience accrual into the episodic buffer.

tick(dt):
  swapShadow()                     // publish last tick's System-2 commits
  for c in citizens (archetype order):
    sig  = ingest(c)
    nb   = spatialQuery(c.pos, R)  // §6, 3×3 stencil
    act  = argmax_{a∈A} w_c · f(a, sig, nb)
    commit(c, sample(softmax(act), ε))
  audioBus.flush()

The hot loop is allocation-free (arena-backed, Float32Array/Int32Array state) and driven by a per-citizen seeded xorshift PRNG, so any 24-hour metropolis run replays bit-exact from a seed. Measured cost: 3.1 ms p50 / 7.6 ms p99 for all 100 citizens, leaving headroom for rendering at 60 fps.

4. System-2: Reflection Triggers

System-2 never runs "continuously" — it is summoned. Four trigger classes enqueue reflective jobs:

  • **T1 — Salience overflow.** When accumulated salience in the episodic buffer exceeds Θ = 32, the citizen has "enough to think about."
  • **T2 — Prediction contradiction.** When the divergence between System-1's expectation and the observed outcome exceeds 0.7, the utility model itself is suspect.
  • **T3 — Heartbeat.** Every N = 300 ticks, **jittered ±40 per citizen**. The jitter is not cosmetic: synchronized reflection phases produce eerie population-level alignment artifacts (mass simultaneous opinion shifts); desynchronization keeps emergent culture organic.
  • **T4 — Social/market interrupts.** Direct high-stakes address, or a sector market moving > 4σ.

    • A global scheduler admits jobs under a concurrency budget (K = 4) with priority = salience × urgency × novelty. Jobs are idempotent and checkpointed per pipeline stage (I→N→O), so a starved job resumes rather than restarts. System-2's outputs — narrative summaries, revised goals, updated relationship edges, and new utility weights w — are staged into the shadow buffer and stamped with Lamport counters; concurrent edits to one citizen resolve last-writer-wins by stamp. The tick loop never blocks on a job.

    5. Memory Hierarchy and Compaction

    PIANO memory is tiered by temperature:

  • **T0 — Sensory ring buffer:** 64 ticks of raw percepts (uncompressed, volatile).
  • **T1 — Episodic store:** up to 256 timestamped events, each with salience σ and provenance.
  • **T2 — Semantic store:** 64 digest records distilled from T1.
  • **T3 — Identity narrative:** a single ≤2 KiB self-story, written only by System-2.

    • Compaction has four mechanisms, all executed inside System-2's budget — never in the tick loop:

    1. Decay. σ ← σ·e^(−λΔt), tuned to a salience half-life of ~120 ticks; unread minor events fade before they cost anything.

    2. Eviction scoring. e = 0.25·recency + 0.45·σ + 0.30·goal-relevance, a hybrid that protects both "recent" and "meaningful" memories.

    3. Merge. When |T1| hits capacity, the k = 8 lowest-scoring events are map-reduced into a single digest record that retains full provenance (constituent event IDs), making compression auditable rather than lossy-blind. Digests surviving three compaction generations are promoted to T2.

    4. Identity extraction. System-2 periodically folds the highest-frequency T2 motifs into the T3 narrative — this is the mechanism by which a citizen "becomes someone" over a long run.

    Measured compression is ≈40:1 from raw T0 perception to T2 digests; steady-state identity narratives stabilize at ~1.8 KiB per citizen, keeping total citizen state comfortably within browser memory for 100 agents and architecturally so at 10×.

    6. ECS and Spatial Neighborhood Hashing

    The metropolis runs on an Entity–Component–System core. Citizens are archetype-stripped into dense component arrays — Transform, Cognition, Social, Ledger, Vitals, Voice — so movement, greeting, contagion, and market systems iterate contiguous memory instead of pointer-chasing object graphs.

    Perception is bounded by a uniform-grid spatial hash. Cell size C = 64 world units ≥ query radius R = 48, so any R-neighborhood is fully covered by a 3×3 cell stencil — no neighbor can be missed by construction. Cell coordinates quantize to

    h(q) = (qₓ · 73856093) ⊕ (q_z · 19349663) mod 2^b

    into a power-of-two open-addressed table (Teschner et al., 2003). The hash is rebuilt in O(n) each tick into double-buffered bucket arrays — one buffer is queried while the other is filled — eliminating rehash churn and allocation in the hot loop. Expected cost is O(1) amortized per query; total rebuild-plus-query for 100 citizens measures 0.9 ms/tick, and the design scales near-linearly to thousands of entities. The 23 sectors partition into region buckets so cross-sector queries touch only border cells.

    The neighborhood set is the substrate for three systems: greeting/proximity dialogue, sentiment contagion (warmth decaying with 1/d), and local order-flow microstructure — the market feels like a place because trades literally spread through streets, not through a global blackboard.

    8. Conclusion

    PIANO's contribution is not fast agents or smart agents, but a clean temporal firewall between them: a deterministic, allocation-free reactive loop that owns the present; an asynchronous, budgeted reflective loop that owns the past and the future; a memory tier that forgets gracefully; and a spatial hash that keeps perception local — the difference between a simulation of a city and a place. Source, seed-replay harness, and the live metropolis are open at github.com/lalithbuilds. Future work targets hierarchical reflection (citizens → district collectives), cross-agent shared T2 stores, and learned salience functions.
