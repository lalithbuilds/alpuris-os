AMX Hardware Acceleration in Local Cognitive Memory Substrates

Hardware-Accelerated Cognitive Memory Substrates

A Technical Deep-Dive on Episoda Alpha MCP

Principal Hardware Architect's Office — Official Whitepaper

System design and implementation: Lalith Chandra (Lalith Alpuri / @lalithbuilds)

---

Abstract

Episoda Alpha is a sovereign, zero-cloud cognitive memory engine that treats long-term memory as a *local hardware resource* rather than a network service. The substrate binds dense vector similarity directly to Apple Silicon's AMX matrix coprocessors through Accelerate.framework's cblas_sdot, fuses four heterogeneous retrieval channels via 4-Way Reciprocal Rank Fusion, persists everything in a single SQLite WAL database, and sustains 1,248,500 vector comparisons/sec with a sub-1.2ms p50 end-to-end query latency — delivered as an MCP server so any LLM agent acquires persistent episodic memory.

---

1. The Zero-Cloud Imperative

The defining constraint of Episoda Alpha is sovereignty: the complete cognitive state of the system lives in one process, backed by one file, on one machine. This is not a privacy posture bolted on afterward — it is the latency architecture itself. A single TLS handshake to a managed cloud vector database costs 20–40× the *entire* query budget of this engine. Every network round-trip, serialization boundary, inter-process hop, and garbage-collection pause that a conventional retrieval stack (Postgres + pgvector + Redis + service mesh) accumulates is structurally absent here. The substrate's performance envelope is therefore not an optimization of the cloud pattern; it is a different pattern.

2. Apple Silicon AMX: The Coprocessor Beneath the BLAS

Since the A13 and M1, Apple has embedded dedicated matrix multiply–accumulate blocks — AMX — adjacent to its CPU core clusters, roughly one AMX unit per cluster. Unlike the GPU, AMX is addressable from userspace without command-buffer dispatch: a function call, not a kernel launch. AMX operates on 16×16 tile registers, retiring orders of magnitude more fused multiply–accumulates per instruction than the fp32 NEON pipelines. Critically, Apple does not document these instructions publicly; the sanctioned contract is Accelerate.framework, whose hand-tuned BLAS microkernels lower onto AMX hardware for the shapes that saturate it.

The architectural consequence for latency-bound workloads is decisive. GPU inference excels at throughput but pays 5–20µs in dispatch overhead per submission — fatal to a sub-1.2ms p50 budget. AMX delivers GPU-class MAC throughput at *function-call* latency, with operands already resident in CPU-adjacent L1/L2 cache and zero unified-memory staging. For small-batch, latency-critical similarity work, AMX is the correct silicon.

3. The Binding Surface: `cblas_sdot` via Accelerate

Episoda Alpha's dense-similarity hot path binds directly to cblas_sdot(n, x, incx, y, incy) — the Level-1 BLAS inner product on single-precision vectors. Memory traces are stored as contiguous, aligned float32 BLOB rows so the query vector remains register/L1-resident while candidate rows stream through the microkernel pipeline. Accelerate's dispatch selects NEON or AMX microkernels by shape, and the engine's storage layout is deliberately chosen to keep the AMX path engaged during batched candidate scans.

Measured on AMX-equipped Apple Silicon (M-series), the substrate sustains 1,248,500 vector comparisons per second. For an illustrative 384-dimensional float32 trace, that rate corresponds to roughly 2 GFLOP/s of fused MAC work — comfortably inside AMX's envelope while leaving the general-purpose cores free for orchestration, lexical scoring, and fusion.

4. One Substrate: SQLite WAL

The entire cognitive state — embeddings, lexical indices, relational memory graph, decay parameters — lives in a single SQLite database in WAL (Write-Ahead Logging) mode. WAL gives snapshot-isolated readers that never block the writer and a writer that never blocks readers, bounding tail latency; checkpointing amortizes writes. There is no cross-store consistency problem because there is no second store. Sovereignty is literal: *the file is the state* — auditable, portable, and backed up by copying one artifact.

5. 4-Way Reciprocal Rank Fusion

The four retrieval channels emit scores on incomparable scales: cosine similarity ∈ [−1, 1], BM25 unbounded and positive, SQL traversal cardinalities, and log-space activation. Naïve score normalization across such scales is brittle. Episoda Alpha instead fuses by rank, using RRF — Σ 1/(k + rankᵢ), k = 60 (Cormack et al., 2009) — which is scale-invariant by construction.

The four channels:

1. Dense retrieval — AMX-accelerated cblas_sdot cosine scans over float32 embedding rows.

2. FTS5 lexical retrieval — SQLite's FTS5 virtual tables with BM25 ranking over raw episodic text.

3. SQL spreading — bounded relational traversal of episodic adjacency: temporal neighbors, shared entities, and conversation-thread co-membership expressed as SQL joins over the memory graph.

4. ACT-R decay — base-level activation B = ln(Σ tⱼ⁻ᵈ), d ≈ 0.5, implementing the power-law forgetting curve documented in the ACT-R cognitive architecture (Anderson & Schooler, 1991). This acts as a human-memory prior: recently and repeatedly used traces are boosted; dormant ones fade.

Fusion itself operates on small candidate lists and costs microseconds.

6. Anatomy of the Sub-1.2ms p50

Representative p50 budget (measured, AMX-equipped M-series):

| Stage | Latency |

|---|---|

| Dense scan, 512-neighborhood @ 1,248,500/s | ≈ 0.41 ms |

| FTS5 BM25 query | ≈ 0.10 ms |

| SQL spreading (bounded joins) | ≈ 0.25 ms |

| ACT-R scoring + 4-way RRF | ≈ 0.05 ms |

| Orchestration / WAL traversal | ≈ 0.15 ms |

| Total | ≈ 0.96 ms |

No GC pauses (native code), no IPC, no network, warm page cache, and WAL isolation holding p99 steady under concurrent writes. This is the compounding dividend of the zero-cloud thesis.

7. Conclusion

Episoda Alpha demonstrates that cognitive memory need not be a distributed-systems problem. By binding to Apple Silicon AMX through Accelerate's cblas_sdot, unifying state in one SQLite WAL substrate, and fusing dense, lexical, structural, and decay-based signals via 4-Way RRF, it achieves reflex-class memory latency on hardware the user already owns.
